# Security policy

## Supported code

Only the current default branch is considered for security review. Historical
AeroCRM revisions are retired, unsupported, and must not be deployed.

## Reporting

Use GitHub private vulnerability reporting for suspected vulnerabilities. Do
not include credentials, personal data, or production policy exports in a
public issue.

## Data boundary

This repository does not require production credentials or employee records.
All future examples and evidence must be synthetic, deterministic, and free of
personal data.
